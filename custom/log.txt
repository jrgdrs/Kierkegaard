# Build targets for Kierkegaard
###

  make build:  Builds the fonts and places them in the fonts/ directory
  make test:   Tests the fonts with fontspector
  make proof:  Creates HTML proof documents in the proof/ directory
  make images: Creates PNG specimen images in the documentation/ directory
  make cpages: Creates custom GITHUB pages as demo folder into pages/ directory
  make cimages: Creates custom PNG preview images into documentation/images/ directory
  make cproofs: Creates custom PDF proof documents into documentation/proofs/ directory
  make cspecimen: Creates custom PDF specimen documents into documentation/specimens/ directory
  make cmaps: Creates custom PDF map documents into documentation/maps/ directory
  make call: Creates all custom documents
